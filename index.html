Trabalhos realizados

Atividades acadêmicas e pessoais que representam minha aprendizagem e minha evolução na computação.

TCC - Sistema de Gestão Energética para Casas de Veraneio

Meu trabalho de TCC. Se trata de um produto embarcado que é implantado na caixa geral de uma casa para mostrar medições elétricas, criar estadias como em um airbnb e mostrar as informações de forma direta e prática para o dono.

ESP32 C++ MQTT Embarcado

Sobre o projeto

Esse foi o trabalho de TCC que eu meus colegas fizemos (nossa faculdade permite fazer o TCC com até 3 pessoas). Se trata de um sistema embarcado com uma ESP32, que o locador coloca no registro geral da casa, e, após isso, o dispositivo consegue fazer leituras elétricas de custo energético por hora, se certos cômodos estão com luz outro aparelho ligado, criar estadias para alugar sua casa (por isso o foco para casas de veraneio), criar planos energéticos para o locatário escolher (se quer só energia, ou energia + ar-condicionado, por exemplo), dentre outros. O foco é tudo ser visível num site que o dono teria acesso, com dashboards interativos e diretos, mostrando de forma facilitada tudo que ele precisa saber energeticamente da suas casa e suas estadias.

Minha participação

Minha participação nesse TCC foi o embarcado em si e o documento para ser entregue. Em relação ao embarcado, trabalhei no código usando C++ para trabalhar com o ESP32, criando a lógica por trás do o que ele fará e como enviará para o Broker MQTT Minha participação no TCC foi voltada ao desenvolvimento da lógica de programação em C++, utilizando o ambiente Arduino IDE para programar a ESP32, responsável por realizar as leituras elétricas no registro geral da residência. Fiquei encarregado de desenvolver o código para processar essas leituras e organizar o envio dos dados ao broker MQTT, permitindo que as informações fossem transmitidas pela rede e posteriormente utilizadas na apresentação dos dashboards do site. Também, mas não menos importante, fiquei encarregado com a documentação para o TCC, o que exigiu conhecimentos de ABNT, metodologia científica e formatação de documentos. Como se trata de um produto feito para TCC e tem possibildade futura, não temos nada para acesso.

Dashboards sobre Microdados Enem

Participei de um trabalho de Probabilidade e Estatística que exigiu a criação de dashboards que mostrassem de forma simples e direta, um dataset de nosssa escolha, filtrando os dados corretamente com python e depois mostrando-os com dashboards em Power BI.

Power BI Python Google Colab

Sobre o projeto

Esse projeto foi mais simples, mas necessário de conhecimentos de estatística, como dados funcionam e devem ser manipulados para evitar ambiguidades ou falsas conclusões. Eu e meu colega escolhemos o dataset Microdados Enem 2020 - 2023 para mostrar os impactos da pandemia nos resultados do Enem. Para isso, tivemos que filtrar os dados no google Colab usando Python e depois passar para o Power BI e estilizar para ser bom visivelmente.

Minha participação

Neste projeto minha participação foi quase totalmente no Power BI, porém precisei verificar o código em Python para validar certos requisitos do trabalho, além de que também cooperei com a finalização e refinamento do código. No Power BI, precisei criar algumas colunas novas para manipular algumas variáveis, criar tabelas novas e relacionamentos, modelar dados e saber dispor isso em cartões e gráficos corretos/condizentes com os dados que quero mostrar.

Sistema de Empréstimo de Equipamentos de Laboratório

Fiz um trabalho em dupla com um colego onde criamos um site que simula um sistema de empréstimo de equipamentos de laboratório, com criação de equipamentos e empréstimos que seriam salvos num banco de dados.

TypeScript JavaScript Supabase PostgreSQL

Sobre o projeto

O trabalho se tratava de uma prova de conhecimentos sobre uso de bancos de dados e saber criar relacionamentos, fazendo um site que demonstrasse isso. Eu e meu colega então decidimos o tema de Sistema de Empréstimo de Equipamentos de Laboratório. Inicialmente criamos em papel a ideia do design das tabelas, suas variáveis e seus relacionamentos, que podem ser visto na imagem 1. Após isso, começamos a fazer o backend e frontend, onde decidimos fazer em React. A base é toda em typescript e javascript. Por fim, refinamos o códigos, criamos um banco online em Supabase, subimos os arquivos para o github e conseguimos fazer o site abrir localmente e enviar tudo e receber do banco de dados online.

Minha participação

Dentro desse trabalho, fique encarregado do tratamento total do banco de dados e os ajustes como enviar para o PostgreSQL (que depois evoluiu para o banco online Supabase) toda vez que uma variável era salva/criada ou um empréstimo era feito; refinamentos no código também. Melhorei alguns visuais como botões, criei algumas interfaces novas, tudo que fosse necessário para a conversa site-banco, além de ajustar trechos necessários, porém, mais focado em relação ao banco, enquanto meu colega ficou com a parte inicial do site, como fazer a estrutura base e boa parte dos visuais, que depois usei/adaptei. Com isso, fiz muito uso de banco de dados (PostgreSQL e Supabase) e uso de linguagens (Typescript e Javascript).

Site do meu Portfólio

Para criar meu portfólio, tive que criar um site em HTML/CSS que mostrasse informações sobre mim, meus conhecimentos, trabalhos e coisas similares, então este site em si também é um trabalho e prova de conhecimento.

HTML CSS GitHub

Sobre o projeto

Para fazer este site, como essencialmente não possuía conhecimentos de HTML e CSS, tive que estudar sozinho e vibecodar, então utilizei, além desses conhecimentos, Gemini, Manus e GPT.

Minha participação

A criação da estrutura básica que fiz foi até fácil, a problemática foi criar os cards no formato que queria, então, com as IA's apenas para suporte, fui criando as estruturas para cada seção do site. Depois de criada as estruturas, modular e ajustar foi fácil; colocar as imagens e alguns detalhes também não foi difícil, uma vez que fui "pegando o jeito", o que por fim levou a estrutura atual do site. Comicamente, meu repositório no GitHub é "recursivo", já que ele mesmo tem o código do site e o site leva ao repositório e ao meu perfil no GitHub. Como eu não sabia praticamente nada sobre, comecei com um arquivo só, então este index.html/site é um arquivo só bruto hardcoded que contém HTML e CSS. O site estará sob constante atualização, então ele também será futuramente melhorado e terá seu código otimizado.
